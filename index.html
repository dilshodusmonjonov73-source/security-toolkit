    Link checker (phishing)

    Paste a link here before clicking it. The site never visits the link, it only analyses how it is written.

      How it works

      • Password: entropy is estimated from length and character variety; common passwords and simple sequences are penalised.
      • Link: the address is split into parts and red flags (IP address, @, look-alike brand names, URL shorteners and more) are scored.
      Educational project. Results are approximate: a "Low risk" result does not mean a link is safe. For important accounts, use a password manager and two-factor authentication.
